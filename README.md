# Web Novels
Web scrapping of novels from websites and convert it into EPUB files.

## Create Virtual Environment (optional)
Continue if you want to handler a controlled version of your packages by project. Otherwise, skip this section.</br>
To create the virtual environment, run the below commands in the terminal inside your project workspace.
``` cmd
python -m venv .venv
```
To activate the virtual env
``` cmd
.\.venv\Scripts\activate
```
To deactivate the virtual env
``` cmd
deactivate
```

## Install Dependencies
To install the project required dependencies, run the following command in the terminal.</br>
***optional**: activate the virtual env before running the command*
``` cmd
pip install -e .
```
